# Creatures

Low-poly animals and creatures by Quaternius (https://quaternius.com), released under CC0 (public domain). Converted from the
original FBX/Blend files to glTF with Blender (materials made opaque) and listed in `src/catalog/creatures.json`
(real length, facing, animation clips). Sources, all CC0 on OpenGameArt:

- Farm Animals (cow, horse, zebra, pig, sheep, llama, pug): https://opengameart.org/content/lowpoly-animated-farm-animal-pack
- Animal Pack Vol.2 (dog, cat, wolf, eagle, piranha): https://opengameart.org/content/animated-animales-low-poly
- Animals Pack (whale, bird, red fox, fish, chick): https://opengameart.org/content/5-low-poly-animals
- Animated Monster Pack (dragon, bat, skeleton, slime): https://opengameart.org/content/lowpoly-animated-monsters
